❓ কীভাবে ব্যবহার করবেন
এই টুলকিট সম্পূর্ণ ফ্রি। শুধু একটি Gemini API key লাগবে।
  1. Gemini API Key নিন (সম্পূর্ণ ফ্রি):
    aistudio.google.com/app/apikey-তে যান → Google account দিয়ে login করুন → "Create API Key" click করুন → Key কপি করুন।
  2. Key সেট করুন:
    উপরে ডানদিকে "API Key দিন" button click করুন → Key paste করুন → Save করুন।
  3. যেকোনো টুল ব্যবহার করুন:
    বাম sidebar থেকে টুল select করুন → ইনপুট দিন → Run করুন।
  4. Key সুরক্ষিত:
    আপনার key শুধু browser-এ�� localStorage-এ থাকে। কোনো server-এ পাঠানো হয় না।
